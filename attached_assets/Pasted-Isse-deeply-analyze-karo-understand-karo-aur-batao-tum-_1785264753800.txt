# Assign Feature — Build Prompt (for Replit Agent)
> Search codebase first — reuse existing Base Modal and base Dropdown. Do not create parallel/duplicate modal or dropdown systems.

---

## 1. Assign Indicator (on Item Card)
- Tiny dot, bottom-right of item image. Not a badge/label.
- Color = assignment status (assigned vs not-yet-created for now; extend later if partial state needed).
- No Assign record ever created for the item → no dot at all.
- Clicking item's "Assign" option opens the Assign Modal.

---

## 2. Assign Modal
Extends existing Base Modal — reuse chrome (backdrop, close, animation).

Header = item name, small/quiet. Top-right always has two icon buttons.
Text hierarchy: role → secondary, resource qty/unit → secondary, margin → tertiary.

**Normal Mode** (default when Assign data exists):
- Top-right: ✎ (edit) / ✕ (close).
- Employees + roles in paired layout, wrapping as needed.
- Resources + qty/unit in paired layout, wrapping as needed.
- Margin bottom-right: `Margin: Rs.{value}`.
- No data at all → show "Not assigned" instead of the block.

**Edit Mode** (default on first-ever open for an item; also entered via ✎):
- Top-right: ✓ (confirm/save) / ✕ (cancel).
- Whole modal gets one edit-highlight (border/glow), not per-field.
- Defaults: employee/role empty, resource name empty, qty = 0, unit = default, Margin = Rs. 0.
- Qty = numeric input only.
- Role & Unit = reused Dropdown component, trigger shows only a ▾ icon, no border/outline.
- ✓ disabled until at least one Resources field is filled (Assign fields don't gate it).
- Cancel before first-ever save → no Assign record created (indicator dot stays hidden).

---

## 3. Edit Dropdown (new reusable file, built on existing base Dropdown)
- Used for Role and Unit fields. Only the ▾ icon styled — no border/outline/box.
- Add generic per-option context menu (long-press/right-click/hover — match existing interaction pattern) with one entry: **Edit**.
- Selecting Edit → inline-editable label for that option.
- Rename should update globally wherever that option is referenced (confirm against how roles/units are actually stored).

---

## 4. Visual Style
Extend existing "Infinity Castle" theme — no new clashing palette.
- Dark obsidian surfaces, subtle indigo-violet gradients.
- Sharp geometric linework, not rounded/skeuomorphic.
- Existing project accent color for edit-highlight, confirm icon, dropdown ▾.
- Subtle glow for edit-mode border.
- Keep primary/secondary/tertiary text hierarchy legible on dark surface.
