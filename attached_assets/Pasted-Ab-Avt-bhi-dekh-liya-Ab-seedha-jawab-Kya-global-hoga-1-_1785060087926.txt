Analyzing potential optimization strategies

Analyzing potential optimization strategies
Haan, ek important optimization hai jo main nazar-andaz kar gaya tha.

Redundancy jo abhi hai
MnItm aur Avt dono useUpld call karte hain — matlab har ek item ke liye upldStore + dropReg mein 2 entries register hoti hain. N items = N×2 registrations.

Global delegation ke baad: 0 registrations, 1 listener.

src={undefined} wali trick — risk hai
Maine kaha tha React undefined prop touch nahi karta — yeh mostly sach hai lekin agar item re-render ho (selection toggle, page flip) aur React img element replace kare, uploaded src kho jayega. Edge case hai lekin real hai.

Better approach: querySelector at upload time — registration nahi, DOM query sirf tab jab file choose ho:

const img = document.querySelector(`img[data-img-id="${id}"]`);
if (img) img.src = objectURL;

Upload ka frequency itna kam hai (user action hai) ke querySelector ka cost negligible hai. Aur element replace hone ka issue bhi nahi — query fresh element milta hai.

Optimized final picture
Kya	Kaise	Overhead
Edit mode UI	CSS class .edit-mode on stage	Zero JS
Drag visual	classList.add/remove by global handler	Zero React state
Click-to-pick	Global delegation [data-item-id]	1 listener total
Drop zone	Global delegation [data-item-id]	1 listener total
Image src update	querySelector(img[data-img-id]) at upload time	Query only on upload
Object URL cleanup	Global Map, revoke on next upload + beforeunload	1 global Map
MnItm aur Avt mein sirf 2 attributes — data-item-id aur data-img-id. Koi hooks nahi, koi props nahi, koi React state nahi upload ke liye.
