Core Mechanic — Button-triggers-element pattern
[EdtBtn]  ──click──▶  edtStore.activate(id, type)
 (has id)               ▼
                  target element pe .edt-on class add hoti hai
                  (pehle koi class nahi thi is element pe)

Edit button alag entity hai — element pe koi "ready to edit" class nahi hoti. Button click ke baad hi target element live classes receive karta hai.

Ek waqt mein sirf ek element active
Agar item-3 edit mode mein hai aur user item-7 ka edit button dabaata hai → item-3 ka .edt-on remove, item-7 ko milta hai. Dono kabhi ek saath active nahi.
